Automated API Testing Tool

Cheack Multiple API Request and automatically verify the response and the expected output

Why I made this

  • Postman needs manual checking of JSON responses, and only one test case can be run at a time.
  • My app automatically compares expected responses with returned responses.
  • Multiple APIs, with multiple JSON requests and different test cases, can be tested simultaneously.
  • Tech stack: React, Node.js, and Express.js.
