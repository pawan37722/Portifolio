Memory capbility Testing

chech you remembering capability by playing a simple game and get your score

Why I made this

  • A memory-testing web game where the player clicks on images to score points.
  • Each new image clicked increases the score by one.
  • If the player clicks the same image twice, the game ends and the score becomes final.
  • Images are reshuffled after every click, so the player has to remember which ones were already chosen.
  • Goal: improve memory and concentration through a simple, engaging game.
  • Tech stack: React, JavaScript, HTML, CSS.
